# CursorMochi v0.1 — 验收矩阵 v2

本文件列的是**需要执行的用例，不是已通过记录**。实施者将实际结果写入 VALIDATION.md，使用 PASS / FAIL / BLOCKED / NOT RUN，附证据。不得预填 PASS。

## A. 分层与构建

| ID | 场景 | 期望 |
|---|---|---|
| A01 | 仅 core/app 的构建和测试 | 不需要 GTK/GIO/native 图形依赖 |
| A02 | 工作区依赖图 | core 无 GUI，app 无 platform 引用，没有环 |
| A03 | 已锁定依赖构建 | --locked 生效；锁文件变更可解释 |
| A04 | 声明的最小 runtime | 只用声明支持的 API，非最新环境实测与否明示 |
| A05 | 部分工具不可用 | 报 blocked，不伪造运行成绩 |

## B. 目录与主题解析

| ID | 输入 | 期望 |
|---|---|---|
| B01 | 三个常见路径都不存在 | 空状态，不崩溃 |
| B02 | 有效 XDG 路径与默认值 | 正确展开；相对 XDG 路径产生诊断 |
| B03 | XCURSOR_PATH 显式覆盖 | 区分发现并集与有效解析顺序 |
| B04 | 同名主题分别提供 default 和 pointer | 保留两处来源，按角色解析，不整套丢弃 |
| B05 | 同名同角色冲突 | 按固定策略选择，与目录枚举顺序无关 |
| B06 | 有 cursors，无 index.theme | 可解析资产可发现；名字从安全来源降级取得 |
| B07 | 仅有效继承信息 | 可解析时列为继承主题，不硬要求本地每个角色 |
| B08 | A→B→A 继承环 | 有界终止，报告链路，其他主题仍可用 |
| B09 | 正常 alias symlink / 断链 / 环 | 正常链可解析，其余明确诊断 |
| B10 | 系统 alternatives 等合法链 | 在明确读取策略内测试，不一刀切或无限放开 |
| B11 | 非 UTF-8 路径 / 同展示名 | 不丢失文件身份、不崩溃，不可应用时禁用写入 |
| B12 | FIFO / 设备 / 超大或持续增长文件 | 不阻塞、不无限读取、拒绝非普通输入 |
| B13 | 上一次扫描后文件被删除或替换 | 请求按新事实失败或刷新，不拿旧缓存伪造成功 |
| B14 | 在额外目录发现但宿主解析不明 | 不宣称写入该名字必然使用这个目录 |

## C. Xcursor 与预览

| ID | 输入/操作 | 期望 |
|---|---|---|
| C01 | 固定静态样例 | 像素、尺寸、热点与人工定义期望一致 |
| C02 | 同一文件多个标称尺寸 | 选择算法稳定，实际尺寸不冒充 nominal size |
| C03 | 多帧不同延迟动画 | 顺序/热点/原始 delay 保留，播放遵循规则 |
| C04 | 透明/半透明彩色边缘 | 通道、字节序、alpha 不串色、不多乘一次 alpha |
| C05 | 非方形图像和热点偏移 | 边界校验，画布不错误拉伸或偏移 |
| C06 | 截断 header/越界 offset/重复 TOC | 有界拒绝或按格式处理，不超额分配 |
| C07 | 乘法溢出/超大计数/帧数/像素总量 | 分配前拦截，返回 LimitExceeded/Invalid |
| C08 | 零延迟/极端延迟 | 有明确播放保护，无忙循环，保留原值诊断 |
| C09 | 当前 A，预览 B | 真实 B 资产；宿主 theme/size 未变化 |
| C10 | 连续快速选择 A→B→C | 迟到 A/B 不覆盖 C 的详情 |
| C11 | 缓存淘汰/反复开关详情 | 受控缓存，纹理引用释放，无无限增长 |
| C12 | 窗口最小化/不可见 | 动画停止无用刷新，恢复时正常 |
| C13 | 工作请求取消/超时 | 不声称阻塞线程已硬终止；队列持续有界 |
| C14 | 继承/回退角色 | 显示实际来源，而非冒称选中主题自带 |
| C15 | 一个主题坏、多数主题好 | 坏条目局部失败，列表与其他预览保持可用 |

## D. 设置与撤销

全部自动用例使用 fake/memory backend，不写真实用户设置。

| ID | 场景 | 期望 |
|---|---|---|
| D01 | GNOME schema 不存在 | 只读降级，不直接构造后崩溃 |
| D02 | schema 存在但非 GNOME 会话 | 不据此开启宿主写入 |
| D03 | key 不存在/类型不符/被锁定 | 禁用相关动作并解释原因 |
| D04 | 打开、刷新、选中、预览 | 写入次数为 0 |
| D05 | 只改主题 | size 不被重写 |
| D06 | Apply no-op | 不新增/覆盖撤销记录 |
| D07 | A→B→C→Undo | 回到 B，清空单级撤销记录 |
| D08 | 原先没有 user override | Undo 对该 key 执行 reset，而不是写默认值 |
| D09 | 计划与写入之间外部变化 | 冲突停止，保留外部状态 |
| D10 | Apply 后外部 C→D，再 Undo | 不自动覆盖 D |
| D11 | setter 返回失败 | 失败可见，不标成功 |
| D12 | 部分写入后失败 | 只对仍属本次写入的项谨慎补偿，记录结果 |
| D13 | 补偿也失败 | 原错误与补偿错误都可见 |
| D14 | 回读延迟或超时 | 显示待确认/不确定，不当作未改变或已全局成功 |
| D15 | 外部通知到来 | 更新当前配置，不覆盖候选选择 |
| D16 | 写操作中再点 Apply/Undo | 串行化，不并发交错 |
| D17 | 重启应用 | 不自动修改设置，单级历史为空 |
| D18 | 关闭窗口时写入未完成 | 不误称取消等于无写入；遵循明确退出流程 |

## E. 隔离 GUI 与真实桌面

GUI fixture 测试仅验证 GUI。Xvfb 的 X11 测试不等于 Wayland 测试；嵌套/无头 compositor 不等于用户实际 GNOME 桌面。

| ID | 环境/操作 | 期望 |
|---|---|---|
| E01 | fixture 启动、选择、预览、退出 | 无真实 HOME 主题访问/无默认 dconf 写入 |
| E02 | 键盘导航与按钮可用性 | 正常控件焦点、可读名称、不仅靠颜色传达错误 |
| E03 | 明暗/高对比样式 | 文字与透明光标有可辨背景 |
| E04 | 100%、200% 与可用的分数缩放 | 标注测试比例；图像与 hotspot 同步缩放 |
| E05 | 原生 GNOME Apply/Undo | 配置值、实际指针分开记证据 |
| E06 | GTK、Qt、浏览器代表窗口 | 分别记生效情况，不由一个窗口推断全系统 |
| E07 | NVIDIA/Wayland 目标环境 | 实际测试与否单列，不由框架支持名单代替 |
| E08 | 不支持/只读桌面环境 | 仍能本地浏览与预览，写入入口明确禁用 |
| E09 | 复制诊断 | HOME/个人目录默认脱敏，无自动上传 |

## 首个里程碑的最低完成线

M4 只读切片：A、B、C 中相关用例自动覆盖，E01/E02 至少在可用 GUI 环境检查。此时仅可称“本地预览原型”，不是完整 v0.1。

完整 v0.1：D 组故障路径测试、M6 的构建/文档检查完成，且至少一个真实目标 GNOME 会话的 E05 有人工证据。真实会话不可用时可以交付代码和候选构建，但应标“候选版本，宿主应用/撤销待验收”，不能升级成“已支持”。

不以测试总数作为唯一质量指标，不为了写出漂亮通过率删掉失败样例。
