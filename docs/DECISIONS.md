# v0.1 实现决策

## 解析策略 xcursor-ordered-v1

按请求的实际文件名逐根搜索，同名主题保留所有来源。直接文件优先；缺角色时采用第一个非空 Inherits 列表并按顺序递归；最后仅在 Missing 时尝试 default。坏文件／环／超限保持错误，不静默伪装成成功回退。role 不做隐式近义词重写：left_ptr、default、pointer 等可以分别选择，文件 symlink 作为实际别名解析。

Inherits 接受逗号、分号、冒号、ASCII 空白；保留文件内顺序。Name 只用于显示，不作为设置键。目录名允许空格，但 Inherits 空格为分隔符，这由参考加载器比对发现。未宣称所有 libXcursor 版本、Qt 或 compositor 与项目策略完全等价。

允许根内链接与 `/etc/alternatives` 中间跳转，最终文件仍须落入声明的读取根。链接深度32，继承深度32、总访问4096；目录枚举16384、单主题角色8192、全目录角色65536。缺失、坏链、非 UTF-8 路径有诊断。元数据256 KiB；输入16 MiB；TOC4096；单边1024；帧2048；单次解码64 MiB。字节序按 Xcursor little-endian 解码为 RGBA premultiplied，GTK 明确使用匹配 MemoryFormat。

文件打开前解析链接，打开时 NONBLOCK/NOFOLLOW，打开后检查普通文件、大小、`/proc/self/fd` 实际路径并有界读取。这不是对同 UID 恶意 rename/mount 的完整隔离；只面向本地已安装资产。

## 调度与缓存

一个工作线程（低于任务书的最多2个），一格待处理请求和一格结果通道。新请求替换待处理请求，用递增 request_id 协作取消扫描／解码，主线程拒绝过期输出。阻塞线程不支持硬终止，退出由进程结束，不作 helper 安全承诺。

LRU 总预算128 MiB，连同输入字节一起计费，比仅计像素更保守。每次预览先重新打开并有界读取，再按完整内容及实际路径命中，避免 mtime 不变的替换误命中。超预算前淘汰；GTK 只持有当前详情动画帧与第一帧纹理，切换清空旧引用。不在整个列表同时播放或创建图像纹理。

动画使用单调累计可见时间，隐藏／最小化期间不累计和渲染。原始 delay 保留，播放 delay clamp 16–10000 ms。名义尺寸不等于实际尺寸，不等于 GNOME 大小，不等于屏幕物理像素。

## 设置

app 使用窄接口，GIO 对象留在 GTK 主线程，文件工作线程不访问 GIO。主题与大小分别按差异写入；无必要使用 delay，不把它包装成数据库事务。独立非延迟 settings 对象回读，主循环每帧周转，最长2秒，回读一致只标 Observed。

setter 失败时逐键检查是否仍为本次写值，才恢复旧 user value 或 reset；补偿也回读。错误及补偿错误同时保留，无法确认则报告 Indeterminate。没有 CAS，不保证消除跨进程竞争。单级 Undo 只在成功观测后替换，no-op 保留；撤销前检查所有相关键。无 Drop 恢复、持久历史、自动启动恢复。

四层边界在真实文件预览 + 隔离 GIO 应用／撤销切片通过后冻结。未新增框架、服务或未来功能 crate。
